# مدونة زراعية

مدونة زراعية عربية مبنية باستخدام Next.js 14 (App Router) وTypeScript وTailwind CSS، مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL).

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000).

## أوامر مفيدة

```bash
npm run build   # بناء نسخة الإنتاج والتحقق من الأخطاء
npm run start   # تشغيل نسخة الإنتاج بعد البناء
npm run lint    # فحص جودة الكود
```
