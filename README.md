# مدونة زراعية

مدونة زراعية عربية مبنية باستخدام **Next.js 16** (App Router) و**React 19** وTypeScript وTailwind CSS، مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL). تُكتب المقالات بصيغة Markdown وتُقرأ تلقائياً من مجلد المحتوى.

## التقنيات الأساسية

- Next.js 16 مع Turbopack
- React 19
- TypeScript
- Tailwind CSS
- `react-markdown` و`remark-gfm` لعرض محتوى Markdown
- `gray-matter` لقراءة بيانات المقالات الوصفية (Frontmatter)

## التشغيل محلياً

يتطلب Next.js 16 إصدار Node.js `20.9.0` أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000).

## أوامر مفيدة

```bash
npm run build   # بناء نسخة الإنتاج والتحقق من الأخطاء
npm run start   # تشغيل نسخة الإنتاج بعد البناء
npm run lint    # فحص جودة الكود باستخدام ESLint
```

## نظام المقالات

توجد جميع المقالات في المجلد `content/posts/` بصيغة Markdown. يقرأ الملف `lib/posts.ts` هذه الملفات باستخدام `gray-matter`، ثم يرتب المقالات تنازلياً حسب تاريخ النشر ويعرضها في الصفحة الرئيسية وصفحاتها الخاصة.

### إضافة مقال جديد

1. أنشئ ملفاً جديداً داخل `content/posts/`، مثلاً `content/posts/composting.md`.
2. أضف البيانات الوصفية (Frontmatter) في أعلى الملف:

```md
---
id: 4
slug: "how-to-make-compost-at-home"
title: "كيف تصنع السماد العضوي في المنزل"
date: "2026-11-24"
excerpt: "خطوات عملية لتحويل بقايا المطبخ والنباتات إلى سماد عضوي مفيد للتربة."
coverImage: "/images/compost.jpg"
---

اكتب مقدمة المقال هنا.

## عنوان فرعي

- عنصر في قائمة
- عنصر آخر

يمكنك استخدام **النص العريض** والعناوين والقوائم وغيرها من صيغ Markdown.
```

3. احفظ الملف. سيظهر المقال تلقائياً في الصفحة الرئيسية، ويُنشأ مساره من قيمة `slug`:

```text
/posts/how-to-make-compost-at-home
```

### ملاحظات حول الحقول

- `title` و`date` و`excerpt` و`coverImage` حقول مطلوبة، ويؤدي غياب أي منها إلى خطأ أثناء البناء.
- `slug` هو الجزء المستخدم في رابط المقال؛ ويُستخدم اسم الملف بدونه إذا لم تكتبه.
- `id` اختياري، ويُستخدم معرّفاً ثابتاً للمقال.
- يتم ترتيب المقالات تلقائياً حسب `date` من الأحدث إلى الأقدم.
- يمكن استخدام صورة من Unsplash أو صورة محلية داخل `public/images/` على شكل `/images/my-image.jpg`.
- إذا أضفت مقالاً أثناء تشغيل خادم التطوير ولم يظهر، أعد تشغيل `npm run dev`.
